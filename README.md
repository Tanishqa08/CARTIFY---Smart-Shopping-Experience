# 🛒 Cartify – Smart Shopping Experience

Cartify is a full-stack e-commerce web application designed to provide a seamless online shopping experience. It includes dynamic product listing, cart management, and API-based data handling.

---

## 🚀 Features

- 🏠 Modern Homepage UI (Amazon-inspired)
- 📦 Product Listing (Dynamic via API)
- 🛒 Add to Cart Functionality
- 🔢 Cart Count Update (Real-time)
- 🔍 Search & Filter Products
- ⬆️ Back to Top Button
- 📱 Responsive Design

---

## 🧠 Tech Stack

### Frontend:
- HTML
- CSS
- JavaScript

### Backend:
- Node.js
- Express.js

### Database:
- JSON (db.json, cart.json)

---

## 🔗 API Endpoints

- `GET /api/products` → Fetch all products
- `GET /api/cart` → Fetch cart items
- `POST /api/cart` → Add item to cart
